Владелец: «надо чтобы сайт ИДЕАЛЬНО по стилям скопировался». Любая правка структуры/CSS не должна
менять вид. Три конкретных правила, выведенных из багов sanjhapunjab (2026-07-22):

1. **Не вкладывать блок в чужой styled-контейнер.** Оборачивая шапку, создавать СВЕЖИЙ НЕЙТРАЛЬНЫЙ
   `<header>` (без id/class) и класть исходные блоки СОСЕДЯМИ. Нельзя переименовать `div#nav` →
   `header#nav` и засунуть баннер внутрь: баннер наследует CSS полосы меню (фон/высота/ширина).
   Исходные блоки не трогать — их id/class несут стили. (`_wrap_nav_in_header`, `_make_header`.)

2. **Локальный файл раньше сети.** Один и тот же ассет часто уже скачан рядом под своим или
   дедуп-именем (`accordion_up.png` и `accordion_up_1.png`). Ходить в архив за тем, что на диске, —
   лишняя копия И риск: под троттлом сеть падает, рабочий файл уходит в «мёртвые». Искать точное имя
   и `<stem>_<цифры><ext>`. (`_recover_css_asset`.)

3. **Резать точечно, а не объявлением.** Мёртвый `url()` вычищать как ТОКЕН, сохраняя цвет/позицию
   в шорткате (`background: #285b8b url(dead) no-repeat` теряет только картинку). Пустое объявление
   после этого убрать — но ТОЛЬКО пустое, не `none`: `display:none` осмысленно. (`strip_dead_css_urls`.)

4. **Оставляемый `<a>` держит `href="#"`, а не теряет href.** Псевдоклассы `a:link` / `a:visited`
   совпадают ТОЛЬКО с `<a>`, у которого ЕСТЬ href. Если чистильщик снимает href у мёртвой ссылки,
   всё оформление, завязанное на `:link`/`:visited`, отваливается — при том что и CSS-правило, и
   картинка целы. Так пропали стрелки аккордеона в сайдбаре sanjhapunjab (`.widget h4 a:link {
   background: url(accordion_up.png) }`): правило есть, файл есть, а `<a>` без href → `:link` не
   срабатывает → стрелки нет. Правило: у ОСТАВЛЯЕМОГО в DOM `<a>` мёртвую ссылку заменять на `"#"`,
   НЕ удалять атрибут — НО ТОЛЬКО В BODY. **УТОЧНЕНО 2026-07-22:** разделять по КОНТЕКСТУ
   (`_neutralize_kept_anchor`): в МЕНЮ (header/nav/footer) мёртвую ссылку убрать СОВСЕМ (владелец:
   «если якорь не присосался — весь хрю удалить», пункт = простой текст `<a class="menu-link">
   <span>…</span></a>` без `href="#"`); в BODY заменить на `"#"` (там `:link`-оформление — стрелки
   аккордеона). Одно правило на всё было НЕВЕРНО: хедер не должен носить фейковые `href="#"`.

**How to apply:** после правки структуры/CSS — рендер Playwright и сверка с архивом ГЛАЗАМИ, отчёт
не гарантирует вид. На каждое ослабление CSS-очистки — негативный тест (`display:none`,
`content:""` не должны пропасть).
