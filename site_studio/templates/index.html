06

Картинки

Автопоиск и скачивание по запросу, без API-ключа
Наведи курсор на превью справа - блок под курсором подсветится и покажет свой селектор, кликни, чтобы вставить его сюда (как выбор элемента в devtools, Esc - отмена). Можно и вписать вручную.
Ищет через настоящий headless-браузер (без API-ключа, без скрейпинг-мусора) и покажет найденное в попапе - сам выберешь, что вставлять.
07

Удалить элемент

Вырезает элемент(ы) целиком из HTML - блок, секцию, что угодно
Наведи курсор на превью справа и кликни ровно по тому элементу, который нужно вырезать (без подъёма к родителю картинки, в отличие от пикера картинок выше). Можно вписать селектор вручную.
08

Убрать битый файл

Красное в Network - вставь путь/URL файла, вычистит все ссылки на него из HTML и подключённых CSS
Ищет по точному совпадению, вхождению строки или просто имени файла - не обязательно вписывать целиком. Из подключённых CSS вырезает конкретное правило (background-image и т.п.), из HTML - src/srcset/href у <img>/<source>/<link>/<script> и инлайн background. Файл с диска не удаляет - если он локальный и стал не нужен, потом прогони «Очистить неиспользуемые картинки».
09

Оптимизация картинок

Чистит мусор в _files и пережимает всё в WebP
Смотрит, какие файлы в папке _files реально упомянуты в HTML и подключённых CSS (включая background-image), остальное уносит в _unused_removed - ничего не удаляется насовсем.
82 - хороший баланс: заметно меньше веса, разница на глаз не видна. Выше 90 почти не уменьшает размер (это уже почти оригинал), ниже 70 - заметны артефакты.
Главный рычаг размера и скорости, не качество: камерафото 4000-7000px+ ужимается до этой длинной стороны перед сжатием - на экране всё равно столько пикселей никто не увидит, а весит и жмётся кратно быстрее.
Через sharp (Node/libvips, вдвое быстрее Pillow на тех же настройках). Конвертирует все локальные .png/.jpg/.jpeg/.bmp/.tiff (в <img>/srcset и в background-image, включая CSS-файлы), переписывает ссылки, удаляет оригиналы после успешной перелинковки. Побайтово одинаковые дубли файлов сжимаются один раз. Битые файлы пропускает и пишет в отчёт. Прогресс смотри в консоли сервера.
