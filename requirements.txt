# Site Studio — Python dependencies
#
# Setup on a fresh machine:
#   pip install -r requirements.txt
#   playwright install chromium          # one-time: downloads the headless browser Playwright drives
#
# Developed/tested on Python 3.13 (3.10+ should work).
# The code also auto-installs anything missing on first run, but installing from here up front is cleaner.
